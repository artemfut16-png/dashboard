# Graphite dashboard

Reference: https://www.behance.net/gallery/253696339/Cyber-Security-Investigation-AI-Analytics-Dashboard

User choice: retain the left sidebar and existing CRM, tasks, projects and analytics workflows

The visual theme is implemented in dashboard-theme.css, loaded after the existing styles by both the published page and source template

- Background #080808, sidebar #0c0c0c, panels #151515, raised surfaces #202020
- Primary text #f2f2f2, secondary text #a3a3a3, borders #292929
- Primary actions and selected navigation use #eeeeee with #111111 text
- Manrope typography, 14px body, 30px page title, 12–13px controls
- Interface containers and controls share a 12px corner radius through --radius-ui
- Status colors are muted green, amber, lavender and red with readable tinted text
- Sidebar 228px, mobile drawer below 860px, two-column mobile metrics
- No decorative dot grids, orange washes or orange key-task frames

Verification: desktop CRM and analytics with isolated demonstration data, mobile analytics at 390px, unchanged application scripts
